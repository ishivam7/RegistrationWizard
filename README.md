# Sprint 7 — Registration Wizard

A responsive three-step React registration wizard implementing the Sprint 7
requirements.

## Features

- Step 1: Personal Information
- Step 2: Account Details
- Step 3: Review & Submit
- React Hook Form
- Zod schema validation
- Real-time validation
- Password/confirm-password validation
- Show/hide password
- Back/Next navigation
- Persistent form values between steps
- Dynamic progress indicator
- Final `console.log()` payload
- Success UI
- Responsive mobile, tablet and desktop layout
- `Prompts.md` AI learning log

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Deployment

This project can be deployed to Vercel or Netlify.

For Vercel, import the GitHub repository. The standard Vite build command is
`npm run build` and the output directory is `dist`.
